### 2. 启动时智能同步（场景A：下载场景）📱
**目标**：SplashPage启动时自动检查并同步最新数据

**流程设计**：
```
SplashPage启动
    ↓
检查WebDAV配置
    ↓
[无配置] → 正常启动
[有配置] → 检查服务器文件
    ↓
[服务器无文件] → 正常启动
[服务器有文件] → 比较时间戳
    ↓
[服务器更新] → 显示"正在同步最新数据" → 下载 → 启动
[本地更新] → 正常启动（运行时会自动上传）
[同时更新] → 显示冲突选择对话框 → 用户选择 → 执行 → 启动
```

**技术要求**：
- [x] 在SplashPage添加WebDAV配置检查逻辑
- [x] 实现文件时间比较算法
- [x] 添加同步进度显示UI
- [x] 实现超时机制（10秒后放弃同步）
- [x] 网络错误处理（显示错误但继续启动）
- [x] 冲突处理对话框

### 3. 运行时自动上传（场景B：上传场景）🔄
**目标**：监听数据库变化，自动上传到服务器

**流程设计**：
```
数据库发生变化
    ↓
防抖延迟（3-5秒）
    ↓
检查网络状态
    ↓
[离线] → 缓存同步需求
[在线] → 检查冲突
    ↓
[有冲突] → 弹出全局冲突对话框
[无冲突] → 后台静默上传
    ↓
更新同步状态
```

**技术要求**：
- [x] 创建全局同步管理器 `AutoSyncService`
- [x] 实现数据库文件变化监听
- [x] 添加防抖机制（debounce）
- [x] 实现同步锁（确保同时只有一个同步操作）
- [x] 后台上传功能
- [x] 全局冲突对话框组件
- [x] 网络状态检查

## 技术架构

### 核心组件

#### 1. AutoSyncService（全局同步管理器）
```dart
class AutoSyncService {
  // 同步状态管理
  static bool _isSyncing = false;
  static Timer? _uploadTimer;
  static StreamSubscription? _dbWatcher;
  
  // 场景A：启动时检查下载
  static Future<SyncCheckResult> checkStartupSync(WidgetRef ref);
  
  // 场景B：开始监听数据库变化
  static void startDatabaseWatcher(WidgetRef ref);
  
  // 防抖上传
  static void scheduleUpload(WidgetRef ref);
  
  // 停止监听
  static void stopWatcher();
}
```

#### 2. SyncStatusWidget（状态显示组件）
- 显示三个时间信息
- 颜色编码状态
- 实时更新

#### 3. ConflictDialog（冲突处理对话框）
- 启动时冲突：阻塞式对话框
- 运行时冲突：非阻塞式全局对话框
